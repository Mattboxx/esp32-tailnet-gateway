ESP32 TAILNET GATEWAY - MATTBOXX EDITION
Firmware v{VERSION}{CHANNEL}
EASY INSTALL - Windows, macOS & Linux
One ESP32. Multiple Tailnet roles. Enable only what you need.

FOR: ESP32-S3 with 16 MB flash and 8 MB PSRAM (N16R8), USB data cable.
NOT FOR: other ESP32 chips. Ethernet (W5500) boards use the separate,
experimental Ethernet image from the release page, not this package.

1. CHOOSE
   New device, or start over ...... INSTALL (erases everything)
   Gateway already set up ......... UPDATE (keeps all settings)
   Web interface language ......... English (standard) or English plus
                                    Italiano, Espanol or Chinese. One
                                    language per image keeps memory free.
   Already set up? The Web UI update is even easier: System > Firmware,
   upload firmware/firmware.bin (or firmware-it/-es/-zh.bin). It keeps the
   previous image as a fallback. GitHub updates then keep that language;
   change it under System > Firmware update > Firmware language.

2. RUN
   Windows (nothing to install; esptool.exe is included):
     windows\INSTALL-NEW-DEVICE.bat      or   windows\UPDATE-KEEP-SETTINGS.bat
     The script asks for the language. Or give the port and language:
       windows\UPDATE-KEEP-SETTINGS.bat COM5 it      (en, it, es, zh)

   macOS / Linux (needs Python 3 and esptool 5, once):
     python3 -m pip install --user "esptool>=5,<6"
     sh macos-linux/install.sh new        or   sh macos-linux/install.sh update
     The script asks for the language. Or give the port and language:
       sh macos-linux/install.sh update /dev/ttyACM0 it      (en, it, es, zh)

   Every script verifies SHA256SUMS.txt, checks that the board is an
   ESP32-S3, and asks you to type ERASE before erasing anything.

3. FIRST START (new device)
   Join the open Wi-Fi ESP32-Tailnet-Setup-XXXX. The setup page opens by
   itself on most phones and PCs; otherwise open http://192.168.4.1/
   Press the BOOT button on the board when asked, create the admin
   password, choose your Wi-Fi, your Tailnet and the gateway role.

TROUBLESHOOTING
   No port found ........ use a data cable and a direct USB port; boards with
                          a CP210x/CH34x chip need its driver; then hold
                          BOOT, tap RESET, release BOOT and retry.
   Not an ESP32-S3 ...... this firmware cannot run on that board.
   Checksum mismatch .... download the package again.
   Linux "permission" ... add your user to the dialout (Debian/Ubuntu) or
                          uucp (Arch) group, log out and in again.
   Interrupted flashing . run the same script again; nothing is bricked.
   Never erase to fix a cable or port problem: it deletes your settings.
