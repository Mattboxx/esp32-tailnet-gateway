# Brand guide — ESP32 Tailnet Gateway, Mattboxx Edition

**Name:** ESP32 Tailnet Gateway — Mattboxx Edition (short: *Tailnet Gateway*).
**Tagline:** One ESP32. Multiple Tailnet roles. Enable only what you need.
**Description:** All-in-one ESP32-S3 Tailscale/Headscale gateway with selective
LAN-to-Tailnet access, subnet routing, remote recovery and optional automation.

Formerly *ESP32 Homelab Gateway* (Mattboxx edition of Csontikka's
*esp32-tailscale-subnet-router*). Community firmware: never present it as an
official Tailscale or Espressif product, and do not borrow their logos,
colours or typefaces. *Tailscale*, *Headscale*, *WireGuard* and *ESP32* are
trademarks of their respective owners and are used only descriptively.

## Logo

The mark is a LAN input entering the ESP32 hub and leaving as three Tailnet
roles. One role is lit; the others are off — *enable only what you need*.
Geometry: 64-unit grid, 4.5-unit round strokes, hub radius 8 with a 3-unit
core, symmetric fan ending at x = 52. **Only black and green** are used; the
mark has no white strokes or fills. It avoids a dot grid (Tailscale) and
chip/red motifs (Espressif). All files are generated by `tools/brand_svg.py`
and rendered by `tools/render_brand_assets.mjs` — edit the script, not the SVGs.

| File | Use |
|---|---|
| `logo-mark.svg` | App icon, favicon, avatar (black tile, green mark) |
| `logo-mark-dark.svg` | Transparent mark for dark backgrounds (greens only) |
| `logo-mark-light.svg` | Transparent mark for light backgrounds (black off-roles, deep-green lit role and hub ring) |
| `logo-mono.svg`, `-black`, `-green` | Single-colour mark; off roles drawn thinner |
| `logo-horizontal-dark.svg` / `-light.svg` | Mark + wordmark lockups |
| `logo-compact.svg` | Stacked mark + "Tailnet Gateway" for small square spaces |
| `banner.svg`, `social-preview.svg` | README hero 1280×400, Open Graph 1280×640 |
| `png/` | Raster exports |

Keep clear space of at least the hub diameter around the mark. Do not
recolour, add gradients, rotate, outline, or place the black tile on busy
photos. Minimum size 16 px; 24 px recommended.

## Colour

| Token | Hex | Use |
|---|---|---|
| Black | `#0A0F0C` | Brand black, tiles, dark backgrounds |
| Black raised | `#111814` | Cards on black |
| Hairline | `#1C2A22` | Borders on black |
| Signal green | `#1FC97A` | Lit role, accent and text on black; buttons with black text |
| Deep green | `#0B7A4B` | Accent and links on white (≥ 4.5:1) |
| Dim green | `#1F5C3F` | Off roles on black |
| Soft / muted green | `#9FDCBE` / `#5E9C7D` | Secondary text on black in brand graphics |

The firmware Web UI and the website use the same greens as their accent.
Semantic colours (danger red, warning amber) stay for errors and caveats only.

## Typography

System stacks, no web-font download (fast, private, no third-party requests):

- UI/text: `Inter, "Segoe UI", Roboto, "Helvetica Neue", Arial, sans-serif`
- Code: `ui-monospace, "SF Mono", "Cascadia Code", Consolas, monospace`

Wordmark: semibold (600–650), sentence case. Edition label: uppercase,
600 weight, letter-spacing ≈ 0.25 em, teal.

## Spacing and shape

4 px base grid; common steps 4, 8, 12, 16, 24, 32, 48, 64. Radius: 8 px
small elements, 10–12 px cards and zones, 14 px icon tile, 16 px diagram panels.

## Iconography and diagrams

Diagrams live in `assets/diagrams/` as editable SVG with `<title>`/`<desc>`
for accessibility. Conventions: solid white arrows = LAN/IP traffic; dashed teal
= WireGuard; dashed red with ✕ = refused; dashed grey outline = optional
module; teal-bordered box = the component doing the work. Captions state
limits, never invented metrics.

## Screenshots

Only authentic captures of a real build, labelled with the version they show.
Concept illustrations must be labelled as such. Never invent metrics,
peers, addresses or results; mask private addresses and identifiers.
