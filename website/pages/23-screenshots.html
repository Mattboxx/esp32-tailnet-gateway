The real firmware Web UI

These images show the actual embedded Web UI, not design mockups or AI-generated images. The Firmware 3.0 examples below render the shipped interface with invented documentation data; the v2.0.0 panel captures were taken from a real ESP32-S3. Neither exposes the owner's network details.

The same built-in interface works in a desktop or mobile browser. The captures are shown in English; the current firmware offers English, Italiano, Español, 简体中文, Français and Deutsch. No separate administration app is required.
