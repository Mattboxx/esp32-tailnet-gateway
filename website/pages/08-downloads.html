One image

Firmware 3.x ships a single image for N8R8 and N16R8 boards with every language and the W5500 Ethernet driver (experimental, off until configured). There are no separate language or Ethernet downloads.

Updating an existing device

On an existing 3.x gateway, back up first (System → Backup). Upload firmware.bin in System → Firmware or use the opt-in updater; settings are kept and a failed boot returns to the previous image. 2.x gateways move to 3.0 as described in Updating. Devices on 1.13 or older that cannot find updates after the repository rename: see the migration note.
