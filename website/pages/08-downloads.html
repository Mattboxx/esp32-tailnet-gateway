WiFi and Ethernet variants

The default images are the WiFi build. An Ethernet (W5500) variant, when published, has eth in its name and is only for boards with that module wired as documented. It is experimental.

Updating an existing device

Back up the configuration first (System → Backup). Upload firmware.bin in System → Firmware or use the opt-in updater; settings are kept and a failed boot returns to the previous image. Devices on 1.13 or older that cannot find updates after the repository rename: see the migration note.
