Verify a download

sha256sum -c SHA256SUMS.txt        # Linux
shasum -a 256 -c SHA256SUMS.txt    # macOS
Get-FileHash firmware.bin -Algorithm SHA256   # Windows PowerShell

All releases and their original installation assets are available on GitHub.

One image

The current firmware ships a single image for N8R8 and N16R8 boards with every language and the W5500 Ethernet driver (experimental, off until configured). There are no separate language or Ethernet downloads.

Updating an existing device

Back up under System → Backup, then use System → Firmware for a Web UI upload or the opt-in GitHub updater. If your device uses an earlier partition layout, use the migration guides before uploading the current image.
