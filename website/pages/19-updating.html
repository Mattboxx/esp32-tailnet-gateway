Updating

An update keeps your settings. A fresh install erases them. Choose the update path unless you want to start over.

Over the air (recommended)

  1. Back up first: System → Backup.
  2. Upload firmware.bin in System → Firmware, or enable the opt-in GitHub update check there.
  3. The gateway writes the free slot, restarts into it and keeps the previous image. If the new image does not start correctly, it returns to the previous one.

Use this method if your gateway is already on the current flash layout.

By USB, keeping settings

Use the browser installer with Erase device unticked, or UPDATE-KEEP-SETTINGS / install.sh update from the Easy Install package.

When a transfer pauses

The bar shows the bytes sent by the browser. Verification happens on the gateway afterwards. Keep power connected and check the running version if the browser loses its connection. If uploads over the Tailnet repeatedly stall, try from the local LAN or use the official GitHub updater.

Earlier flash layouts

Older gateways may need a different partition layout before the current image will fit. Back up first and choose the guide for the version shown in System.

  • Update from a 1.x release if your original updater can no longer find the repository.
