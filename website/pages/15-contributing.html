Contributing

Bug reports, hardware reports, guide fixes and translations are as welcome as code.

Ways to help

  • Hardware report: tell us which board you used and what worked.
  • Guide feedback: point out a confusing step or a missing case.
  • Translations: review the Web UI wording in your language.
  • Code: open an issue first for anything non-trivial.

Build and test

git clone --recurse-submodules {{repo}}
cd esp32-tailscale-gateway-NAS-recovery
pio run -e esp32-s3
python -m unittest discover -s tools -p 'test_sensitive_scanner.py'

The embedded source on Main remains the published 1.13 baseline until the new firmware is qualified and released. The expanded Firmware v{{next_version}} suite is not published yet.

Follow the test instructions for the published source. Device tests can change a real board; run them only on your own test hardware.

Rules

  • Never commit credentials, real addresses, tailnet names or device backups.
  • Keep changes focused; update the changelog and affected guides.
  • Follow the code of conduct.
