Device recovery

Losing Wi-Fi or a bad setting never erases your configuration, and the gateway never falls back to an open network once it has been set up.

The home Wi-Fi is unavailable

About a minute after the saved Wi-Fi disappears, the gateway opens its own protected Wi-Fi with the name and password you chose during setup. Join it, open http://192.168.4.1/, sign in with the admin password and correct the Wi-Fi settings. When the uplink returns, that network closes again (unless you keep it always on).

Gateways installed before v{{next_version}} may still use the firmware's shared default access-point password. The Network page warns about it: set your own password there.

An update did not start

Over-the-air updates keep the previous image. If the new one does not start correctly, the gateway returns to the previous image by itself. Check Tools → Reset history afterwards.

Reinstall by USB

  1. Keep settings: browser installer with Erase device unticked, or UPDATE-KEEP-SETTINGS / install.sh update.
  2. Start over: erase and install, then follow the first boot. Restore a backup afterwards (System → Restore).

If the computer does not see the board: hold BOOT, tap RESET, release BOOT, then retry. The ROM bootloader inside the chip cannot be overwritten by a failed install.

Forgotten admin password

Connect USB, open a serial console at 115200 baud and run web_password <new password>. Or erase and reinstall; a backup made earlier restores your configuration.
