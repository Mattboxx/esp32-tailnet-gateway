Versioning

ESP32 Tailnet Gateway uses semantic versioning. Stable is the default update channel. Enable beta if you want GitHub prereleases to be eligible for installation.

How versions compare

A stable release ranks above the beta builds with the same version number. For installation or an older flash layout, see Updating.

Upstream credit

System → About shows the firmware version and build commit. Release provenance identifies the exact Mattboxx/microlink revision. See NOTICE.md for original authors, component licences and legal-material supplements. Older archives have matching notices described in the licence audit.
