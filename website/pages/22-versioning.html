Versioning

Earlier builds carried the upstream release they were aligned with plus an edition number, for example 0.1.38-Mattboxx-1.13. Since Firmware v2.0.0 the product has its own semantic version: 2.0.0, then 2.0.1, 2.1.0 and so on. Each version is tested as numbered betas first, 2.0.4-beta.1, 2.0.4-beta.2 and so on, published as GitHub pre-releases; the stable 2.0.4 then ranks above all of them. Gateways on the default stable channel receive stable releases only; on the beta channel they receive the highest version, beta or stable.

The product name does not change with the version: it is always ESP32 Tailnet Gateway — Mattboxx Edition. The number appears only as the firmware version.

How versions compare

Every 2.x release is newer than every earlier 0.1.x-Mattboxx build. Updaters from 1.10–1.13 cannot read the new numbers, which is why a bridge release exists (see Updating).
