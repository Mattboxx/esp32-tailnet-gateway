First boot

This guided first start arrives with firmware v{{next_version}}. The current stable download, Mattboxx 1.13, starts as described in Getting started.

A new gateway configures itself like a home router: join its Wi-Fi, open the setup page, and answer a few questions. No serial tools, IP knowledge or Tailscale experience needed.

  1. Install the firmware from the browser installer or the Easy Install package.
  2. Power the board. After a few seconds it opens an open Wi-Fi network called ESP32-Tailnet-Setup-XXXX (XXXX identifies your board).
  3. Join that network with a phone or computer. Most phones and PCs then show a sign-in notification or open the setup page by themselves.
  4. If nothing opens, open http://192.168.4.1/ in a browser. This address always works while the setup network is active.
  5. Confirm it is yours: press the BOOT button on the board once. No reachable button? Connect USB, open a serial console at 115200 baud and type the 8-digit setup code it prints.
  6. Secure your gateway: create the admin password (at least 8 characters). There is no default password.
  7. Connect to Wi-Fi: pick your home network from the list, enter its password and press Test connection. Your phone may lose the setup network for a moment; it reconnects by itself.
  8. Connect your Tailnet: paste a Tailscale or Headscale auth key, or skip and do it later from the dashboard.
  9. Choose your gateway role: connect a device to your Tailnet, connect a network, IoT gateway, wake or recover a NAS/PC, Home Assistant & automation, or advanced configuration. Also name the gateway's own Wi-Fi and set its password.
  10. Finish: the summary shows where the gateway will be, then it saves everything and restarts. Rejoin your home Wi-Fi and open a link from the last page: the address received during the Wi-Fi test, or the displayed .local name. The default is http://esp32-tailnet-xxxx.local/, where xxxx is the code of its setup Wi-Fi; a configured hostname can replace it. The client and LAN must support mDNS. If name resolution is unavailable, use the tested IP address. Once enrolled, the gateway's tailnet name is another option. Sign in, and the guide for the role you chose opens once.

Why the setup network is open, and how it is protected

The setup Wi-Fi has no password so that any phone can join it, but only a gateway that has never been configured opens it. An existing installation, including one updated from 1.13, never does.

  • Only the person holding the board can pair: the BOOT button or the console code must confirm, and only one pairing at a time is allowed.
  • Passwords and keys are encrypted in your browser before they cross the open network (X25519 key agreement and AES-256-GCM).
  • While unconfigured, the gateway exposes no other function and forwards nothing to your home network.

Remaining risk: someone nearby, during the few minutes of setup, could imitate the setup network with a fake one. Set the gateway up where you can see it.

Later, without Wi-Fi

If the home Wi-Fi disappears, the gateway opens its own protected Wi-Fi (the name and password you chose) after about a minute, so you can sign in and fix the settings. That recovery network never uses the open setup mode. See Device recovery.
