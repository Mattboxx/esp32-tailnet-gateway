The problem it solves

A home-automation controller, a printer dashboard or an old PC needs to reach one service at another site — an MQTT broker, a NAS web UI, an SSH host. It cannot run Tailscale, and you do not want to advertise whole subnets or replace the router. Put an ESP32-S3 on the same LAN and publish one rule: this device may use this Tailnet service on this port.

Honest limits

This is a microcontroller running userspace WireGuard on one shared 2.4 GHz radio. It suits control traffic, telemetry, dashboards and SSH, not video or bulk transfers. It is community firmware, not an official Tailscale client. Read the FAQ and the security model before deploying it.
