Getting started

New device? Install from the browser or with Easy Install, then follow the guided first boot. The steps below describe manual configuration.

These steps describe the current stable 1.13. Firmware v{{next_version}} adds a guided first boot.

You need: an ESP32-S3 N16R8 board, a USB data cable, a 2.4 GHz WiFi network, and a Tailscale account or a Headscale server (0.26 or newer).

1. Flash the firmware

Download the Windows package from the downloads page and run CLEAN_INSTALL_ERASE_ALL.bat for a first install. On Linux or macOS:

python -m pip install esptool
esptool.py --chip esp32s3 --baud 921600 write_flash 0x0 firmware-factory.bin

2. First-time setup

Join the setup access point (default ESP32-TSR-Setup; its name and password are printed on the serial console), open http://192.168.4.1, set an admin password and rename the access point.

3. Join your WiFi

Under Network, select your 2.4 GHz network and save. Reserve a fixed address for the ESP32 on your router.

4. Enrol on your tailnet

  1. Create a reusable, non-ephemeral auth key (Tailscale admin → Settings → Keys) or a Headscale pre-auth key.
  2. In Tailscale, paste the key, set a hostname and, for Headscale, the login server URL.
  3. After it appears in the admin console, disable node-key expiry and reboot the ESP32 once.
  4. Approve any advertised routes.

5. Publish your first service

Follow the Service Gateway guide: add a rule with a single-device source, run Test destination, then enable it.

Verify

  • Status shows the uplink connected and Tailscale running with peers.
  • tailscale ping <esp-hostname> answers from another node.
  • The rule's accepted counter grows when the LAN client connects.

Common problems

An unapproved route, node-key expiry left on, or a peer ACL that does not include the ESP32 cause most first-day issues. See Troubleshooting. Detailed walk-through with screenshots: docs/GETTING-STARTED.md.

Security

Set the admin password before joining any shared network. The local Web UI is HTTP: administer it from a trusted LAN or over the tailnet.
