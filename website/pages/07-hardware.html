Hardware

Reference target

SoCESP32-S3 (dual core, 2.4 GHz WiFi)
Memory16 MB flash, 8 MB octal PSRAM (N16R8), e.g. ESP32-S3-DevKitC-1 N16R8
PowerReliable USB supply, separate from the machines it should wake
OptionalmicroSD card for the log flight recorder

Other ESP32 families are not drop-in targets. Community reports for other ESP32-S3 boards are collected in docs/HARDWARE.md; please add yours with the Hardware report issue form.

W5500 Ethernet (experimental)

The separate esp32-s3-eth image supports an explicitly wired W5500 SPI module: off by default, explicit pins, DHCP or static IPv4, WiFi-first or Ethernet-first. It is host-tested only and not validated on real hardware. Never flash it onto a board without the module wired as documented in docs/ETHERNET.md.

Single radio

Firmware v2.0.2 keeps all four interface languages in the WiFi build. The experimental W5500 build serves English only to stay within its application partition.

The uplink and the access point share one 2.4 GHz radio and channel. After a roam to a different channel the device realigns the AP, which briefly interrupts AP clients.
