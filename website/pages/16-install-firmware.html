Install Firmware

Connect your ESP32-S3 and install ESP32 Tailnet Gateway directly from your browser.

{{flasher}}

How it works

  1. Connect the ESP32-S3 to this computer with a USB data cable.
  2. Open this page in Chrome or Edge on Windows, macOS, Linux or ChromeOS.
  3. Press Connect & Install and choose the board's serial port in the browser prompt.
  4. Choose Install. The browser asks whether to erase the device first (see below).
  5. Wait until the installer reports success, then unplug and power the board normally.
  6. Continue with the first start: join ESP32-Tailnet-Setup-XXXX and follow the setup page.

New device or update?

Install on a new device

For a board that has never run this firmware, or one you want to reset. Tick Erase device when asked: all settings, saved Wi-Fi and the tailnet identity are removed, and the gateway starts the guided setup.

Update an existing device

Prefer the gateway's own update: System → Firmware in the Web UI keeps every setting and falls back to the previous image if the new one does not start. If you must use USB, leave Erase device unticked: settings are kept and the board boots the new image from its first slot.

Never tick Erase device to fix a connection problem: it deletes your configuration. Back up first (System → Backup).

Supported browsers

The installer uses the Web Serial API. It works in desktop Chrome and Edge (and other Chromium browsers) on Windows, macOS, Linux and ChromeOS. Safari, Firefox and phone browsers do not offer Web Serial; use the Easy Install package instead.

If the board is not found

  • Use a cable that carries data, not a charge-only cable, and a direct USB port.
  • Close any other program that uses the serial port (serial monitors, PlatformIO, Arduino IDE).
  • Boards with a USB-to-UART chip may need its driver (CP210x or CH34x). Boards using the ESP32-S3 native USB need none.
  • Still nothing: hold BOOT, tap RESET, release BOOT, then try again.

Technical details: the installer writes the bootloader at 0x0, the partition table at 0x8000, the initial OTA data at 0x19000 and the application at 0x20000, taken from the project's partitions.csv. It is ESP Web Tools 10.4.0 (Apache-2.0), served from this site.
