Frequently asked questions

Can I run Tailscale on an ESP32?

This project runs a community Tailscale-compatible client on an ESP32-S3 with 16 MB flash and 8 MB octal PSRAM (N16R8). It supports selected gateway and recovery jobs without a Linux server. It is not the official Tailscale client, does not support every ESP32 board, and does not promise all official-client features. See supported hardware and the security model.

Can I connect IoT devices that cannot install a VPN client?

Yes, for supported TCP/UDP services. A LAN device can connect to a specific ESP32 listen port, or a WiFi device can use the ESP32's IoT access point. These are different paths: choose the selective LAN-to-Tailnet gateway or AP gateway for your use case. Neither automatically relays multicast discovery between homes.

Is this an official Tailscale client?

No. It is community firmware built on the microlink stack, compatible with Tailscale and Headscale coordination servers. It is not affiliated with Tailscale Inc.

Does it work with Headscale?

Yes, with Headscale 0.26 or newer. Set the login server and use a pre-auth key. HTTPS servers need a certificate from a public CA; self-signed certificates are not supported.

What is the difference between the Service Gateway and a subnet router?

The Service Gateway lets LAN devices reach one specific Tailnet service through the ESP32 (LAN → Tailnet). A subnet router lets tailnet clients reach LAN devices (Tailnet → LAN). You can use both.

How fast is it?

It is a microcontroller doing userspace WireGuard on a shared 2.4 GHz radio. Upstream measured roughly 0.3–1.4 Mbit/s through the tunnel; the current candidate has not been benchmarked. Use it for control, telemetry, dashboards and SSH, not video or bulk transfers.

Does the LAN client need any software?

No. It connects to the ESP32's LAN address and listen port like any other server.

Is the source filter enough security?

It limits which addresses can use a rule, but an address is not an identity. Restrict rules to single devices, keep the peer's ACL tight and set an admin password.

Can it turn on my NAS?

It can send Wake-on-LAN if the NAS supports it and has standby power, then check a port. It cannot hard-reset a frozen machine or provide KVM/BIOS access.

Which boards are supported?

ESP32-S3 with 16 MB flash and 8 MB octal PSRAM (N16R8). Other ESP32 families are not supported. W5500 Ethernet is experimental and only in a separate build.

Does it send telemetry?

No. There are no usage reports or crash uploads. GitHub update checks happen only when you enable them or press a button.

Do I need MQTT or Home Assistant?

No. Every integration is optional; the Service Gateway, Web UI and manual Wake-on-LAN work without them.

Is tailnet lock supported?

No. The device cannot sign its own node key; disable tailnet lock or pre-authorize the node.
