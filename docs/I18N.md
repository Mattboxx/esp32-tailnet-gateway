# Web UI languages

The embedded Web UI ships in **English, Italiano, Español and 简体中文**.
English is the source language and the fallback. The language is detected from
the browser (`navigator.languages`) and can be changed in
**System → Interface mode → Language**; the choice is stored only in that
browser (`localStorage`), never on the device.

## How it works

- Dictionaries live in `main/i18n/<code>.json` as `{ "English text": "translation" }`
  and `main/i18n/languages.json` lists the languages that are built in.
- `main/gen_index_html_gz.py` injects one compact bundle at build time. Keys
  are FNV-1a hashes of the English text (the English already ships in the
  page); a hash collision fails the build.
- At run time the UI replaces whole text nodes, `placeholder`/`title`/
  `aria-label` attributes and `confirm()` messages whose English text matches
  a key. A `MutationObserver` translates content rendered later. Keys
  containing `{}` are patterns for sentences assembled at run time
  (`Last updated {}`); the value in `{}` is copied unchanged.
- Typed values, addresses, ports, keys and anything inside `code`, `pre`,
  `textarea` or `[data-no-i18n]` are never changed.

## Coverage (honest numbers)

`python tools/i18n_extract.py --coverage` measures the extracted strings:
it ≈ 94 %, es ≈ 94.5 %, zh ≈ 95 % at this checkpoint. The rest are product
names and technical terms deliberately kept in English (SSID, MAC, CPU,
Tailscale, GPIO names, example addresses). Sentences assembled from several
run-time pieces that have no pattern yet stay English. Validation fails below
90 %.

## Flash budget

Three languages add about 56 KB to the gzip-compressed page (measured; the
build also minifies the page, saving about 25 KB). Firmware use after adding
them: WiFi build 95.1 % of the 1,920 KB app slot, Ethernet build 97.9 %.
French and German translations exist in `main/i18n/disabled/` but are not
built in to keep OTA headroom; enabling one costs roughly 18 KB and needs a
fresh size check, especially for the Ethernet build.

## Adding or fixing a translation

1. `python tools/i18n_extract.py` refreshes `main/i18n/source.json`.
2. Edit `main/i18n/<code>.json`; keep numbers, units, `/32`-style values,
   `tskey-auth-…` and similar tokens exactly as in English.
3. Run `python tools/i18n_extract.py --coverage` and the browser suite; check
   narrow phones (320 px) for long words.
