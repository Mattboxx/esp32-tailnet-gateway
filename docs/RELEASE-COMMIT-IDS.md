# Release commit ids

On 8 November 2026 the commit messages of this repository and of the MicroLink
fork were edited (attribution lines removed). File contents are unchanged:
every edited commit has the same files as before, and the MicroLink submodule
entries point to the edited MicroLink commits with the same files. Commit ids
changed from the first edited commit onwards.

Release assets published before that date (`source-provenance.json`,
`SOURCE-COMMIT`, notices) name the earlier ids. This table maps each released
reference to its commit before and after the edit, so those records stay
verifiable: check out the "now" commit and the source files are the ones the
release was built from.
