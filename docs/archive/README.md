# Archive

Historical records kept for transparency: superseded plans, maintainer and
agent handoffs, validation campaigns, audits and the README of the former
*ESP32 Homelab Gateway*. They describe earlier versions and are not
maintained; current behavior is in the [documentation index](../README.md)
and the [changelog](../../CHANGELOG.md).

`flash-package-1.4/` is the Windows package of firmware `0.1.19-Mattboxx-1.4`.
Do not use it for a new installation: download the
[latest release](https://github.com/Mattboxx/esp32-tailnet-gateway/releases/latest)
or use the [browser installer](https://mattboxx.github.io/esp32-tailnet-gateway/install-firmware/).
