# Code of conduct

ESP32 Tailnet Gateway is a small community project. Everyone who opens an
issue, discussion or pull request is expected to:

- be respectful and assume good intent; disagree about code, not people;
- keep reports factual and reproducible, and never share someone else's
  credentials, addresses or network details;
- respect that the maintainers are volunteers with limited time;
- credit other people's work, including upstream authors.

Harassment, personal attacks, discriminatory language, doxxing and spam are
not tolerated. Maintainers may edit or remove such content and block
repeat offenders.

Report conduct problems privately to the maintainer through GitHub
(<https://github.com/Mattboxx>) rather than in a public thread.

This text is adapted in spirit from the
[Contributor Covenant](https://www.contributor-covenant.org/), version 2.1.
